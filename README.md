# 《无职转生：人生模拟器》玩家指南

> 『即使在这个残酷而真实的世界里，我也想认真地活下去。』

基于《无职转生》全 26 卷正传、外传与《蛇足篇》的硬核文字人生模拟。肉身是脆弱的凡胎，NPC 有独立人格，世界不围绕玩家运转。

## 快速开始
发送 `/start`，选择 **降生时代 → 出身 → 一项不可逆缺陷特质**，即可开始。

## 指令

| 指令 | 变体 | 作用 |
|---|---|---|
| `/start` | `/开局` | 建卡向导，或指定角色直接降生 |
| `/status` | `/状态` | 查看当前状态卡与世界线节点 |
| `/save` | `/存档` | 导出存档代码块（可存入 `saves/`） |
| `/load` | `/读档` | 粘贴存档继续人生 |
| `/roll [项目] [DC]` | `/检定` | 四维判定 + 公开 D100 |
| `/canon` | `/顺应正史` `/原史同调` | 顺应正史见证者模式 |
| `/sync [对象]` | `/校准` | 联网核查并校准角色或事件 |

## 玩法特点
- **日式排版**：台词 `「……」`，心声 `『……』`。
- **每轮三件套**：正文 + 状态锚点卡 + 2~4 个选项，其中一条固定是【原史同调 / 顺应正史】。
- **顺应正史模式**：作为同行者或见证者重温原著，不改变历史。
- **凡人代价**：断喉必死、断肢无法再生、魔力透支昏迷，死亡不可逆。
- **微观步进**：除非你要求快进，每轮只推进当前场景到数日。
- **按需考据**：开局、关键史实节点、`/canon`、`/sync` 或存疑时才联网核查，日常推进不卡顿。
