## 四、AI Agent 检索与调用指令

AI 仲裁者或规划器可通过 `scripts/query_novel.py` 执行统一多维度检索：

```powershell
# 1. 检索外传中的特定关键词（如拉普拉斯、死神齐格、王龙王）
python scripts/query_novel.py "拉普拉斯" --gaiden

# 2. 精确限定外传系列（如古龙昔话、专职篇、蛇足篇）
python scripts/query_novel.py "龙神" --gaiden --series "古龙昔话"

# 3. 仅提取外传中的原著对白与心理独白
python scripts/query_novel.py "齐格" --gaiden --dialogue

# 4. JSON 纯净结构化输出供上下文注入
python scripts/query_novel.py "人神" --gaiden --json --limit 3
```
