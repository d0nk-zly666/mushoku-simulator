## 一、为什么 AI 会“聊着聊着就忘了原著”？（底层技术解密）

很多玩家在跑团时，一开始把完整的设定集复制给 AI，前十轮体验惊艳，但到了二三十轮、甚至上百轮后，AI 开始：
- 遗忘自己身处魔大陆还是阿斯拉王国；
- 记错角色的年龄、剑术位阶与魔力储量；
- 把老卢迪未来日记里的悲惨未来（洛琪希惨死）当成了正史既定现实；
- 忘记奥尔斯帝德身上被所有人厌恶的诅咒，把龙神写成了热情好客的NPC；
- 逐渐退化为通用起点爽文语调，出现“系统商城”、“无脑升级”等违和内容。

这**不是你的提示词写得不够多，而是由现代大语言模型（LLM）的底层运行机制决定的**：

```
[ 用户早期输入的 8.3 万字设定 ] ────► 随着多轮对话推移 ────► [ 被滑动窗口挤出 / 截断丢失 ]
                                                                       │
[ 用户最新输入的单句话 ] ◄──── 注意力衰减（Lost in the Middle） ◄───────┘
                                                                       │
                                                         基座模型通用偏见漂移
                                                    （退化为最普通的平庸网文）
```

1. **上下文滑动窗口截断（Sliding Window Truncation）**：
   大模型单次对话的记忆容量是有限的（通常为几万至数十万 Token）。在多轮交互中，系统为了装下最新的对话，会**自动将最顶部的早期内容削减或丢弃**。你一开始发给它的完整设定，在聊到第 30~50 轮时早已被系统完全丢出了视野。
2. **中间迷失与注意力稀释（Attention Dilution & Lost in the Middle）**：
   即使某些模型拥有 100 万 Token 的超大窗口，大模型对“正文最开头”和“最近几句”的注意力权重最高，对处于上下文“中间长篇”的记忆检索能力会产生断崖式下跌。
3. **基座预训练语料漂移（Prior Drift）**：
   当上下文中的强约束设定逐渐淡化，模型内部海量的预训练通用语料就会占领主导地位，导致 AI 自动滑向普通的二次元萌系、爽文模板或机械化答复。

### 1. 第一层：系统级置顶持久化
- **原理**：普通用户消息会被滑出窗口，但 **系统提示词（System Role / System Prompt / Workspace Rules）** 会在每一轮对话构建时由底层自动拼接在上下文最前端，具备最高优先级。
- **现成文件**：我们已在工作区为您创建了：
  - [AGENTS.md](file:///e:/无职转生/AGENTS.md)：工作区唯一的系统级最高规则文件；
  - [RUNNER_SYSTEM_PROMPT.md](file:///e:/无职转生/RUNNER_SYSTEM_PROMPT.md)：专用于 ChatGPT、Claude、SillyTavern、本地 WebUI 的纯净系统提示词；
  - [.cursorrules](file:///e:/无职转生/.cursorrules)：专用于 Cursor / Windsurf / VSCode 的智能体规则。

### 2. 第二层：动态状态快照协议（State Snapshot Protocol）
- **原理——“以回声对抗失忆”**：
  大模型生成下一句话时，距离它最近、权重最高的信息就是**它上一轮自己刚输出的末尾文本**！
  我们强制要求 AI 在每一轮回答末尾附带标准的【状态锚点卡 2.0】。这样一来，当前的甲龙历时间、精确地理位置、魔力状态、同行角色羁绊、正在进行的事件等核心数据，在每一轮都被重新刷新并写在上下文末尾，形成永久锁死的记忆闭环！
- **状态锚点卡 2.0 标准结构**：
  ```markdown
  ❖ 六面世界 · 动态状态锚点卡 2.0 (Status Anchor)
  - 【甲龙历纪年】：甲龙历 417 年 5 月（季节：初夏）
  - 【地理位置】：中央大陆 ＞ 魔法三大国 ＞ 拉诺亚王国 ＞ 魔法都市夏利亚
  - 【环境危机等级】：白级(极度安全)
  - 【角色属性】：阿兰 ｜ 人类/下级骑士之子 ｜ 15岁 ｜ 魔法大学二年级生 ｜ [缺陷特质: 负债累累/魔力经络狭窄]
  - 【肉身与心智】：健康度: 正常 ｜ 心智/创伤: 稳定勤勉
  - 【魔力存量】：75% [档位: 充沛]
  - 【战力位阶】：
    * 剑术：水神流初级 ｜ 斗气缠绕: 未觉醒
    * 魔术：水/土双系中级 ｜ 咏唱: 短缩咏唱 ｜ 魔眼: 无
  - 【重要随身资产】：练习用细剑、大学制服、阿斯拉银币12枚
  - 【同行者与核心羁绊】：菲兹（希露菲）：阶段[同行] ｜ 友善同班学长；鲁迪乌斯：阶段[陌生] ｜ 知晓其名尚未深交
  - 【当前短期目标】：通过期末魔术构筑实战测试，赚取下学期学费
  - 【世界因果纪事】：菲托亚转移已过去数年；鲁迪乌斯正在调查转移灾害真相
  ```

### 3. 第三层：断章归档与无痛换房（Context Refresh）
当一局游戏玩到 80~100 轮以上时，即使模型不遗忘，上下文庞大也会带来生成变慢、消耗额度过高的问题。
只需输入 `/save`，复制 AI 生成的终极存档卡，在新窗口/新对话中粘贴并输入 `/load [存档内容]`，即可实现**零损耗继承全部人生经历与人物羁绊**！

### 4. 第四层：8 大高内聚专题知识库与 CLI 极速检索 (knowledge/01~08)

### 6. 第六层：微观场景零跳步与原著情节链闭环律 (Micro-Scene Zero-Skip Protocol)
- **拒绝大而化之的跳步概括**：AI 最容易犯的错误是将一个包含多个转折的复合大事件（如绑架受囚、地牢审讯、交锋突围）在一轮回复中直接推至终局结果，抹杀了玩家体验原著微观沉浸的乐趣；
- **场景步进六联环**：推演必须步步为营，深潜至【当前具体空间与物理站位 ➔ 双方肢体试探/言语交锋 ➔ 意外受挫/肉体痛感与施暴反馈 ➔ 关键微观台词与耳语压制 ➔ 心理防线动摇与认知重塑 ➔ 场景自然转折】；
- **微观受挫与反抗细节零省略**：原著中角色经历的真实磨难（如艾莉丝地牢叫骂被绑匪痛殴踢踹、鲁迪肉身护卫厉喝闭嘴等）绝不可省略！
- **联网检索深潜细节**：每次调用 `search_web` 必须深潜至微观场景、动作、台词与受挫细节，坚决杜绝大而化之。

## 四、跑团实操快捷指令与保姆级技巧

在与 AI 跑团的过程中，你可以随时使用以下系统控制指令，AI 会严格服从：

| 快捷指令 | 触发效果与作用场景 |
| :--- | :--- |
| `/start` | 启动开局建卡引导向导，选择时代、出身、天资并生成首张状态卡 |
| `/status` 或 `/状态` | 当你觉得当前状态不够清晰时，要求 AI 详细展开当前所有属性与因果细节 |
| `/save` 或 `/存档` | 要求 AI 生成标准的存档代码块，用于备份或跨新会话使用 |
| `/load [代码块]` | 读入历史存档，瞬间恢复到之前的进度与情境 |
| `/roll [技能名] [难度]` | 进行公开掷骰检定（例如：`/roll 潜行 65` 或 `/roll 剑神流拔剑术 70`） |
| `/sync [人物或事件]` | 强制纠偏指令！例如 `/sync 洛琪希` 或 `/sync 奥尔斯帝德`，强制 AI 检索设定集校准原著人设，杜绝 OOC |
| `/canon` 或 `/顺应正史` | 开启或锁定【顺应正史见证者模式】（含 `/canno`、`/cannon` 等错拼容错），剧情严格贴合原剧情发展，不对未来剧情做出改变，以见证者与同行者视角沉浸体验原汁原味的无职世界，不产生蝴蝶效应 |

### 遭遇 AI 偏离原著时的“十一大核心唤醒咒语”（全景升级版）：

1. **纠偏人设**：
