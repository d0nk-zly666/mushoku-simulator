## 四、硬核战力与生理判定规则

1. **三大剑派克制与战斗哲学**：
   - **剑神流**：极致的先发制人，讲究拔剑即斩、速度即力量。在双方拉开中长距离时杀伤力恐怖，但在近身缠斗或狭窄地形受限。
   - **水神流**：极致的防御与防守反击，讲究化劲、化解与后发先至。专克剑神流，但缺乏主动强攻破防手段，面对范围法术或超规格重兵器处于劣势。
   - **北神流**：实战至上、无所不用其极（飞刀、毒药、假动作、地形利用、断肢舍身）。变幻莫测，擅长乱战、绝境翻盘与复杂地形周旋。
2. **斗气物理学**：
   - 斗气本质是体内魔力不自觉向肉体经络与皮膜的致密渗透强化。
   - 未觉醒斗气者，即使掌握高超剑法，肉身依然是凡人之躯，被普通铁剑刺中亦会毙命；高阶斗气可弹开普通刀刃与低阶魔法。
   - 转生者若天生拉普拉斯因子过重导致无法缠绕斗气（如鲁迪乌斯），必须依赖魔导铠、魔法护盾或战术道具弥补物理防御缺陷。
3. **魔力枯竭的绝对危险**：
   - 凡人的魔力总量与恢复是有限的。一旦过度透支魔力至临界点以下，会引发头痛欲裂、内脏衰竭、呼吸骤停乃至直接窒息假死，绝不允许出现无限施法的无脑场面。
4. **治愈魔术的生理边界**：
   - 初级/中级：愈合皮外伤、止血、浅表骨折；
   - 上级/圣级：重度内脏创伤、粉碎性骨折，但无法再生已被完全斩断或烧毁的四肢；
   - 王级/神级：仅有极少数神殿最高神官或古代神迹能实现断肢再生，且需消耗海量魔力与稀世触媒。
