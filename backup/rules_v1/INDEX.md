## 六、智能极速检索 CLI 工具 (`query_lore.py` & `query_novel.py`) 联动指南

除了直接查看 Markdown，本工作区还配备了两大纯 Python 原生极速检索命令行工具：[`scripts/query_lore.py`](file:///e:/无职转生/scripts/query_lore.py)（知识库核心枢纽）与 [`scripts/query_novel.py`](file:///e:/无职转生/scripts/query_novel.py)（228.8万字原著小说语料检索器），可在终端或自动化脚本中实现微秒级精确查询：

### 常用命令示例：

```bash
# ==================== 1. 设定与知识库检索 (query_lore.py) ====================
# 全文关键词极速检索（大小写不敏感，带精准高亮与上下文窗口）：
python scripts/query_lore.py "预知魔眼"
python scripts/query_lore.py "aqua heartia"
python scripts/query_lore.py "黄金斗神铠" -m 03

# 角色声音指纹与反 OOC 台词禁令快速调取（支持标准名与江湖别名）：
python scripts/query_lore.py -c "艾莉丝"
python scripts/query_lore.py -c "泥沼"                  # 智能识别别名 -> 鲁迪乌斯
python scripts/query_lore.py -c "狂犬"                  # 智能识别别名 -> 艾莉丝
python scripts/query_lore.py -c "龙神"                  # 智能识别别名 -> 奥尔斯帝德
python scripts/query_lore.py --list                    # 一键列出全域 32 位角色清单

# 人神（Hitogami）白色房间十次托梦机密直接调取：
python scripts/query_lore.py -d 2                      # 直调第 2 次托梦（利卡里斯买肉巧遇奇希莉卡赠预知眼）
python scripts/query_lore.py -d 8                      # 直调第 8 次托梦（夏利亚地下室毒鼠绝杀与日记救赎）

# 年份正史编年史大事件定位（自动去重与时空回溯分析）：
python scripts/query_lore.py -y 425
python scripts/query_lore.py --timeline 417

# 【原史同调 / 顺应正史见证者模式】规则直调与选项生成指南：
python scripts/query_lore.py --canon                   # 调取顺应正史模式规范与每轮选项固化生成指南
python scripts/query_lore.py --canon --json            # 纯净结构化 JSON 输出供 Agent 快速解析

# 跨库双轨联动：检索知识库的同时一并检索原著小说语料库：
python scripts/query_lore.py "水龙" -w                 # 同时命中知识库条目与原著小说相关章节

# ==================== 2. 全景语料库极速检索 (query_novel.py) ====================
# 正传全语料极速检索（283章 228.8万字）：
python scripts/query_novel.py "洛琪希"
python scripts/query_novel.py "水神流" -n 5            # 限制返回前 5 条
python scripts/query_novel.py "九头龙" -v 12           # 仅在正传第12卷检索

# 外传语料库极速检索（8大分支 162章 90.2万字）：
python scripts/query_novel.py "拉普拉斯" --gaiden      # 专搜外传（古龙昔话/专职篇/蛇足篇等）
python scripts/query_novel.py "芝士人" -s "专职篇"      # 限定外传系列检索
python scripts/query_novel.py "龙鸣山" -s "古龙昔话"    # 限定古龙昔话
python scripts/query_novel.py --list-gaiden             # 列出外传 8 大分支大盘表

# 正传 + 外传 319 万字双库联搜：
python scripts/query_novel.py "死神" --all              # 双库全域联搜

# 微观对白专用检索（仅匹配角色台词「……」与内心独白『……』）：
python scripts/query_novel.py "鲁迪" --dialogue
python scripts/query_novel.py "齐格" --gaiden --dialogue

# 结构化纯净 JSON 输出（供 Agent 自动化调用）：
python scripts/query_novel.py "奥尔斯帝德" --json
python scripts/query_novel.py "初代龙神" --gaiden --json
```
