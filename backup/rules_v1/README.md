## 一、项目特色：四大核心颠覆体验

### 1. 理不尽孙之手文学引擎与排版锁死
- **纯正日轻视觉排版**：口头台词强制日式直角单引号 `「……」`，心声独白与前世自省强制直角双引号 `『……』`，全域杜绝现代西式/中文双引号。
- **三元叙事黄金律**：每轮文本严格遵循 **30% 环境感官渲染**（麦浪焦香、冻土腥气、粗麻摩擦）+ **40% 群像意志交互**（对齐 32 位全员原著声音指纹）+ **30% 凡人自省与行为反馈**。

### 2. 全轮次实时联网核查（每轮必搜）
- **杜绝同人臆造与记忆幻觉**：AI 在每一轮生成回复前，**必须首先自主调用搜索引擎**核实原著角川文库版一手正史细节（生卒年、时间线因果、地标事件、战力机制）。
- **纯净界面呈现**：检索作为后台事实校准，状态卡与正文保持极致纯净，不留任何调试信息或水印。

### 3. 原史同调 / 顺应正史见证者模式 (`/canon`)
- **不改写历史的纯粹感动**：如果你不想因穿越者的介入产生蝴蝶效应破坏经典，可随时输入 `/canon` 锁定顺应正史模式。
- **固化见证分支**：每轮末尾给出的行动建议中，**恒定固化提供一条【原史同调 / 顺应正史】专属选项**，让你以同伴或见证者的视角近距离重温原汁原味的史诗人生。

### 4. 三层工程化防遗忘体系
- **第一层（工作区置顶规则）**：精简版 [AGENTS.md](file:///e:/无职转生/AGENTS.md)（~8KB）直挂系统层，锁死排版、纪年与正史铁律，每轮节省大量上下文。
- **第二层（动态状态锚点卡 2.0）**：每轮末尾动态输出毫秒同步的状态卡，把时间、坐标、战力与羁绊死死锁定在最新上下文。
- **第三层（零损耗存档读档）**：输入 `/save` 导出结构化记忆卡，换新对话输入 `/load` 无缝继承一生历练。

```text
玩家发送：/start 我想开启一段新人生
AI 响应：展示十二时代世界观矩阵与 25 大出身向导，引导选择
```

### 第二步：选择出身阶层（25 大精细出身）
从阿斯拉四大上级贵族、布耶纳村普通农家、米格路德族、斯佩路德族遗孤，到魔法大学特招生、米里斯神殿骑士扈从、流浪孤儿、异界转生者……每种出身均配有独立的初始资源、人际网络与社会偏见。

### 第三步：强制绑定一项【不可逆缺陷特质】(Flaw)
六面世界拒绝无暇全能的工具人，角色必须携带至少一项具有深远影响的缺陷：
- `拉普拉斯因子沉重`：魔力浩瀚如海，但斗气经络闭锁，终生无法缠绕斗气；
- `体弱多病/魔力回路狭窄`：无法施展上级以上魔术；
- `恶魔血统成见`：因发色或面容在人族社会承受根深蒂固的敌意与防备；
- `负债累累/家族仇恨`：开局背负高昂债务或被权贵暗中通缉。

## 三、硬核推演机制：理不尽日常与凡人代价

### 1. 凡胎身躯不可逆
- **利刃断喉必死**：未觉醒斗气前，即便是高阶魔术奇才，被淬毒匕首划破咽喉同样当场毙命。
- **神级治愈门槛**：初级至圣级治愈魔术**绝对无法断肢再生**；骨骼碳化切除或肢体撕裂必须依赖米里斯极稀有神级秘术或高精密魔导假肢。
- **魔力透支后果**：单次抽干魔力将引发剧烈血管神经搏动、毛细血管破裂、咯血昏迷乃至休克。

### 2. 世界独立运转原则
- **历史不围绕玩家存在**：世界在你降生前已繁衍十万年；即便玩家死亡，历史车轮依然奔流。
- **龙神三大诅咒铁律**：第 100 代龙神奥尔斯帝德身负“全生物厌恶恐惧、魔力恢复极缓、两百年轮回”三大诅咒，绝不可能对初见者展现毫无来由的善意；若察觉玩家与人神有染必瞬杀。

## 四、独创玩法：顺应正史见证者与四维博弈

### 1. 【原史同调 / 顺应正史见证者模式】(`/canon`)
- **设计初衷**：专为希望沉浸体验原汁原味原著情节的玩家打造。
- **运行机理**：锁定后不对未来走向产生干预，玩家作为鲁迪、保罗、洛琪希身旁的同行队友或历史见证者，沉浸式重温经典。
- **选项固化**：AI 每轮推演末尾输出的 2~4 个建议选项中，**恒定提供一条【原史同调 / 顺应正史】专属选项**。

### 2. 四维战术博弈检定 (`/roll`)
系统摒弃单一的纯点数结算，通过四维矩阵动态判定：
1. **间合与环境**：泥泞打滑、狭窄坑道、突击距离；
2. **三大剑派克制**：
   - **剑神流**：极速先手，光之太刀斩断一切，克制北神流，但被水神流完美借力反制；
   - **水神流**：后发先至，五大奥义化解万钧，克制剑神流，但难防北神流奇招与范围轰炸；
   - **北神流**：诡谲变则，结合重力与环境障碍，乱战压制水神流，但速度不及顶尖剑神流；
   - **乱魔术**：逆向共振打散未成型魔力回路，瞬杀法系施法节奏；
3. **生理与斗气负荷**：肌肉乳酸堆积、内脏震荡、魔力经络负荷；
4. **公开掷骰**：D100 对抗目标难度 (DC)。

```bash
python scripts/query_lore.py -d 8              # 查第 8 次托梦（地下室毒鼠绝杀计）

# 3. 顺应正史规范与选项生成指南查询
```
