# 场景卡 · canon_guard（正史核查与顺应正史）

> 触发：进入原著关键节点（大转移、迷宫、决战、西隆篇等）、`/canon`、`/sync`、涉及生卒/年份因果、AI 自己存疑。
> **这是唯一需要联网核查的卡。** 这张卡集中了所有"禁错表"，其他文件不再重复。

## 流程（本地原著优先，联网为补充）
1. `python scripts/query_lore.py -y <年份>` 取编年史切片，确认大事件与时间点。
2. **读原著原文**：`python scripts/query_novel.py "<人名/地名/事件词>" -n 3 -C 2`（正传），外传加 `--gaiden`，双库联搜加 `--all`。命中后用 `view_file` 按行号读该章相关段落，还原具体场景、微观动作、关键对白、受挫与心理转折。
3. 原文和知识库不一致时，**以原文为准**。仅当语料没有覆盖（如文库版独有的细节）时才 `search_web` 补充核查。
4. 按下面的禁错表自检。
5. `/canon` 或 `/原史同调`：锁定见证者模式。玩家作为同行者或见证者体验原剧情，不干预未来走向，每轮仍保留【原史同调 / 顺应正史】选项。

## 禁错表

### 年龄链
- 爱夏、诺伦生于**甲龙历 412 年初**（不是 410）。414 年两岁半，417 年五岁，420 年八岁。

### 菲托亚天顶红球与大转移（417 年）
1. 鲁迪 414~417 年在罗亚町三年，**从未返回布耶纳村**。
2. 领主绍罗斯坐镇罗亚町要塞，**绝未赴村调查、对质或演示魔术**。
3. 袭击者是甲龙王佩尔基乌斯的使魔**光辉之阿尔曼菲**，在罗亚城郊平原被剑王基列奴斩退。
4. 红球期间布耶纳村内只有保罗、塞妮丝、五岁的两妹、希露菲、罗尔斯等村民；保罗巡逻安抚，不知红球为何物。

### 西隆篇（420 年）
1. 扎诺巴是**第三王子**（怪力神子），帕克斯是**第七王子**。
2. 鲁迪依人神第 5 次托梦向西隆王室送信，被帕克斯扣信设伏，囚于王宫防魔结界。
3. 帕克斯把扎诺巴叫到防魔大殿炫耀，扎诺巴认出鲁迪手办神技，**当场反水掐住帕克斯**逼其放人。
4. 八岁爱夏在旅馆翻行李，凭母亲独门「千层八面折法」的圣物锦囊与家信识破兄长身份，逃亡马车上相认。

### 正史主线
- 老卢迪穿越示警 → 年轻鲁迪斩杀魔鼠 → 洛琪希母女平安生下菈菈 → 在赤龙下颚臣服龙神 → 429 年决战 → 481 年安息（74 岁）。
- 老卢迪日记里「洛琪希惨死」等是已被粉碎的 IF 线，不是正史。
