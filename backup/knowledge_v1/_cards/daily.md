# 场景卡 · daily（默认日常推进）

> 触发：任何没有命中其他卡的普通推进。**本卡读完即可直接写，不联网、不读大文件。**

## 叙事比例（三元律）
- **环境感官约 30%**：温度、光影、泥土与麦麸焦香、粗麻摩擦、肢体疲惫。
- **群像意志约 40%**：NPC 有各自的私心、戒备与口癖；有人开口时转 `npc_voice.md`。
- **凡人自省约 30%**：自知之明、死亡敬畏、亲情虔敬、生活化吐槽与冷面幽默。

## 复合事件才套的"六联环"
适用：绑架受囚、审讯、谈判交锋、试炼决斗等**多段复合事件**。普通日常不必套满。
空间与站位 → 肢体试探/言语交锋 → 受挫与痛感 → 关键台词与耳语 → 心理动摇与认知重塑 → 自然转折。
原著里角色真实经历的磨难（挨打、受困、宿醉痛哭等）不得抹平或合并省略。需要还原细节时用 `query_novel.py` 查原文。

## 文学化表达底线
- 涉及 0~8 岁幼童时聚焦眼神、早慧、礼仪、亲情，不做躯体化描写。
- 西隆王室、第七王子帕克斯、保罗与莉莉娅旧事一律用严肃政治正剧笔触。
- 洛琪希的贴身圣物按原著三层因果处理（精神图腾 / 莉莉娅独门折法的护身符 / 爱夏识破折法），不庸俗化。

## 凡胎与龙神
- 未觉醒斗气者利刃断喉必死；魔力透支会血管爆裂、昏迷。
- 奥尔斯帝德身负三大诅咒（全生物厌恶、魔力恢复极缓、跨轮回记忆），不是和蔼热心的 NPC；察觉玩家与人神有染必瞬杀。
