# 场景卡 · timeskip（岁月结算）

> 触发：玩家**明确**要求快进（如"快进到三年后"）。没有这类要求，不得自行快进数年。

## 流程
1. 联网或 `query_lore.py -y <起止年份>` 核查这段时间的历史大势。
2. 输出【岁月流转结算面板】，五维：
   1. **纪年与年龄**：起止甲龙历、生理年龄。
   2. **技能与体魄**：剑术、魔术、斗气进展与伤病。
   3. **世界大势**：这段时间的正史大事。
   4. **人神暗线**：是否有托梦、使徒活动。
   5. **羁绊离合**：NPC 关系阶段变化。
3. 结算后落到一个具体场景，继续微观推进，并附状态卡与选项。
