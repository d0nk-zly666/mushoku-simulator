# 场景卡 · save_load（`/status` `/save` `/load`）

## `/status`
输出完整状态锚点卡（模板见 `daily.md`）与当前因果节点。

## `/save`
输出一个代码块，存档可写入 `saves/` 目录。格式：

```text
【存档 · 无职转生人生模拟器】
纪年: 甲龙历 xxx 年 x 月 ｜ 年龄: xx
角色: 姓名 / 种族 / 出身 / 缺陷特质
身心: 健康度 / 创伤 / 魔力%
战力: 剑术阶位 / 魔术阶位 / 斗气
随身物:
羁绊: NPC(阶段)…
当前目标:
世界线节点:
正史偏离点: （玩家已改变了什么；/canon 模式下写"无"）
模式: 普通 / 顺应正史
近期剧情摘要: （3~5 句，含最后一个场景与未完成的对话）
```

## `/load`
解析存档，用一小段场景接续，输出状态卡与选项（含【原史同调 / 顺应正史】）。核对纪年与年龄一致；如涉及关键节点，转 `canon_guard.md`。
