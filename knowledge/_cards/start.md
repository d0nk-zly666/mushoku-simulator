# 场景卡 · start（`/start` 建卡与降生）

## A. 未指定角色：建卡向导（不输出状态卡）
1. 先在 `knowledge/08_模拟器运行规则_交互指令与检定系统.md` 中查找 `^## 第四十九章` 所在行，用 `view_file` 从该行读到文件末尾（第四十九章「正式启动界面与十二大时代抉择」），展示十二时代矩阵。
2. 先在 `knowledge/04_势力政体_文明支柱与偏见阶层.md` 中查找 `^## 第七章` 与 `^## 第八章` 所在行，用 `view_file` 读取第七章区间（第七章「25 大精细出身与天赋谱系」），展示出身列表。
3. 引导玩家选定：**时代 → 出身 → 一项不可逆缺陷特质（Flaw）**。
4. 此阶段不输出状态卡。

## B. 指定角色或完成建卡：降生
1. 联网核查该角色或时代的正史生卒与关键年份（本卡属于"关键核查"触发情形）。
2. 运行 `query_lore.py -c <角色>` 取关键 NPC 的声音指纹。
3. 写降生叙事（微观场景，不快进），输出首张状态卡与选项（含【原史同调 / 顺应正史】）。
